# legacy-ts (reference only)

This is the original v3.1 TypeScript foundation (Zod contracts, Drizzle schema, policy / keys / MCP stubs).
From PRD v3.2 all business logic lives in `backend/` (FastAPI + Pydantic). Use these files only as a
reference while porting contracts to `backend/app/contracts`. It is not built, linted or tested by CI.
Delete this folder once the port is done.
